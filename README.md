# AstraSync Contract Decision Dashboard

Dashboard for the AstraSync AI/ML contract case. It compares three pricing options using the present value of AstraSync's contribution (1.5% monthly discount rate, 18 months).

Sections: Summary · Analysis · Illustration (decision tree) · Sensitivity Analysis · Conclusion

## Files
- `index.html`: the dashboard
- `images/decision_tree.png`: decision tree
- `images/gain_share_hist.png`: simulated gain-share histogram (R, 10,000 runs)
